### Features
- Customizable background
  - Custom Gradient
  - Custom Image
- Search Bar
  - Multiple search engine support
- Categories & Shortcuts
  - Organize your shortcuts into customizable categories
- Clocks
  - Show seconds
  - Show date
  - Support for 12-hour and 24-hour formats
- Weather widget
  - Temperature
  - Humidity
  - Wind speed
  - Chance of rain
